# 발표 파일

이 폴더의 `steps.json`, `descriptions.json`, `*.mmlab`은 **`build.mjs`가 생성**합니다.
파일을 손으로 고치지 말고 스크립트를 고친 뒤 다시 실행하세요. `source/`의 두 파일은 생성기가 읽는 원본입니다.

```bash
node presentation/build.mjs                  # 단계 파일 다시 생성
node bench/presentation-content-check.mjs    # 실제 페이지에서 모든 단계 계산·검증
```

검증 스크립트는 헤드리스 크로뮴으로 페이지를 띄워 각 단계를 불러오고 `계산`을 실행한 뒤,
모든 블록이 오류 없이 계산되는지와 `값 보기` 블록이 생성기가 예측한 값을 내는지 검사합니다.
디스크의 파일이 생성기와 다르면 실패합니다.

## 단계

| id | 파일 | 내용 |
| --- | --- | --- |
| `00a` | `00a-input-blocks.mmlab` | 숫자, 변수, 값 생성기, 값 보기 |
| `00b` | `00b-math-blocks.mmlab` | 사칙연산, 브로드캐스트, max, 같음?, 합, 내적, 행렬×벡터, 지수, 로그 |
| `00c` | `00c-control-blocks.mmlab` | 값 바꾸기, 반복 번호, 둘 다 계산 (카운터, 제곱 합, 피보나치) |
| `00d` | `00d-user-blocks.mmlab` | 사용자 블록: ReLU, 제곱, 블록 안의 블록 |
| `01` | `01-perceptron.mmlab` | 퍼셉트론 직접 조립 → 퍼셉트론 블록 → AND · OR · NAND 게이트 블록 |
| `02` | `02-xor.mmlab` | 게이트를 쌓아 XOR 조립, XOR 게이트 블록 |
| `03` | `03-linear-fail.mmlab` | 활성화 없는 선형 모형을 델타 규칙으로 학습, XOR 실패 (손실 1.0에서 멈춤) |
| `04` | `04-threshold-search.mmlab` | 임계값 2-2-1 신경망: 손으로 넣은 가중치로 표현 확인, 무작위 탐색으로 학습 |
| `cnn-train` | `cnn-1-train.mmlab` | Quick Draw 15종 CNN: 무작위 초기값에서 `계산`으로 1 epoch 학습 (테스트 정확도 6.7% → 81.3%) |
| `cnn-trained` | `cnn-2-trained.mmlab` | 같은 CNN에 60 epoch 학습 가중치를 넣은 상태: 그림별 예측 평가 87.6%, 손그림 분류 |

## 파일 형식

- `steps.json`: `steps` 배열 순서가 발표 순서입니다. 각 항목의 `id`는 고유해야 하며 `file`은 이 폴더 기준 경로입니다. `title`은 화면에 표시됩니다.
- `descriptions.json`: 단계 `id`에 설명 문자열을 대응시킵니다. 줄바꿈은 `\n`으로 적습니다. 일반 텍스트로 표시되며 HTML은 실행되지 않습니다. 설명이 없거나 빈 문자열이면 설명 칸을 숨깁니다.
- `*.mmlab`: 편집 모드의 내보내기와 같은 형식입니다. 진리표 벡터(`x1 = [0,0,1,1]` 등)와 색인 벡터는 `runtimeVariables`에 저장된 값으로 들어 있습니다. 해당 변수 블록의 설정(형태, 길이, 초기값)을 바꾸면 서명이 달라져 저장된 값 대신 초기값으로 되돌아갑니다.

## 생성기 구조 (`build.mjs`)

- 사용자 블록은 `defineBlock`으로 한 번 정의하고 여러 단계에서 재사용합니다. 의존하는 블록(`uses`)은 자동으로 함께 포함됩니다.
- 하나의 입력을 블록 안에서 여러 곳에 쓰려면 `값 보기` 블록으로 갈라 씁니다(입력 포트 하나 = 슬롯 하나).
- 배치는 열 300px, 행 190px 격자입니다. 입력이 3개 이상인 블록은 190px보다 높으므로 행 간격을 넓혀야 합니다.
- `계산`은 블록을 만든 순서(id 순)로 한 번씩 계산하므로, 반복이 끝난 뒤의 값을 보이려면 반복 블록보다 나중에 만든 변수 블록으로 읽습니다.
- CNN 단계는 `source/quickdraw-cnn.mmlab`(편집 모드의 학습 작업공간)에서 사용자 블록 정의와 변수 설정을 그대로 가져오고, `source/quickdraw-cnn.mmlweights.json`을 학습된 단계의 저장 값으로 넣습니다. 원본과 다른 점은 `build.mjs`의 CNN 절 머리 주석에 정리했습니다(평가용 순전파 복제 제거, 둘 다 계산 사슬을 '차례로 실행' 블록으로 묶기, 가중치 갱신이 새 모멘텀을 쓰도록 연결, 파라미터별 한 줄 배치).
- CNN 정확도는 생성기에서 흉내내기에 계산이 커서 페이지에서 잰 값을 `CNN_MEASURED`에 적어 두고, 검증 스크립트가 다시 재서 비교합니다. 구조나 가중치를 바꾸면 다시 재서 고치세요.
- 3단계 경사하강과 4단계 탐색은 페이지와 같은 float32 계산과 같은 난수(`js/values.js`의 LCG)로 미리 흉내내어 기대값과 설명에 들어갈 숫자를 만듭니다.

## 발표 모드 동작

- 발표 모드를 켤 때 목록과 설명을 새로 읽고 1단계로 시작합니다. 이전/다음 이동은 항상 해당 `.mmlab`을 다시 요청합니다. 발표 중 수정·학습한 내용은 이동 시 버려지므로 필요하면 먼저 내보내세요.
- 발표 중에도 편집·학습·불러오기·내보내기를 사용할 수 있습니다. 내보내기는 `presentation-copy-날짜.mmlab`을 다운로드하며 GitHub에 쓰지 않습니다.
- 발표 모드를 끄면 진입 직전 편집 작업공간과 가중치, 내 블록, 화면 위치, 데이터, 손그림을 복원합니다. 발표 중에는 편집 자동 저장과 내 블록 저장을 덮어쓰지 않습니다.
- GitHub에 파일을 올린 뒤 웹사이트 배포가 완료되어야 반영됩니다. 웹사이트와 같은 출처의 `presentation/` 파일을 읽습니다.
