# Machine Learning Math Project

수학 동아리 개인 심화 탐구 발표를 위한 **블록형 수학 실험 도구**입니다.

핵심 원칙은 하나입니다.

> 발표 시작 시점에는 신경망이 완성되어 있지 않는다. 발표 중 수학 블록을 연결하면서 신경망을 직접 만든다.

## 현재 구현

- 드래그 가능한 블록 작업공간
- 출력 포트 → 입력 포트 연결
- 일반 수학 블록
  - 숫자
  - 더하기 / 곱하기
  - 제곱 / 합 / 평균
- 그림 입력
- 그림을 28×28 값으로 변환
- 28×28 값을 784차원 벡터로 펼치기
- 블록 그래프 실제 계산
- 선택한 블록의 수학식과 현재 값 표시
- Quick, Draw! 15개 카테고리 데이터 선택 및 로드
- 선택한 카테고리의 실제 28×28 샘플 미리보기
- 각 카테고리 10,000장, 784바이트/장 형식의 `.bin` 데이터 사용

## Quick Draw 데이터

`data/` 폴더에 다음 15개 카테고리가 있습니다.

- cat / fish / house / tree / car
- apple / clock / star / umbrella / airplane
- face / flower / cup / bicycle / guitar

각 `.bin` 파일은 `10,000 × 784 = 7,840,000`바이트입니다.
픽셀 하나는 0~255의 `uint8` 값이며, `dataset.js`에서 필요할 때 0~1의 `Float32Array(784)`로 바꿀 수 있습니다.

페이지에서 선택한 카테고리만 메모리에 로드합니다. 기본 선택은 cat / fish / house입니다.

## 의도적으로 없는 것

현재 코드에는 다음을 **미리 구현하지 않습니다.**

- `NeuralNetwork` 클래스
- 완성된 신경망 레이어
- 가중치/편향 전용 블록
- 학습 버튼
- 역전파 구현
- 경사하강법 구현

이 기능들은 발표 내용이 정해지는 과정에 맞춰, 일반 수학 블록에서 어떻게 만들어지는지를 보여주는 방향으로 추가합니다.

## 실행

정적 HTML/CSS/JS 프로젝트입니다.

`index.html`을 직접 열어도 되며, 이 경우 Quick Draw 데이터는 저장소의 raw 파일에서 불러옵니다.

로컬 서버를 쓰려면:

```bash
python -m http.server 8000
```

그 뒤 `http://localhost:8000`으로 접속합니다.
