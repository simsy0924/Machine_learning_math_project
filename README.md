# Machine Learning Math Project

수학 동아리 개인 심화 탐구 발표를 위해 만든 **블록형 수학·머신러닝 실험 도구**입니다.

핵심 목표는 완성된 신경망을 가져다 쓰는 것이 아니라, **신경망을 이루는 수학을 직접 조립하고 역전파까지 직접 정의해서 실제 학습을 수행하는 것**입니다.

> 발표 시작 시점에는 완성된 신경망도, 자동으로 미분해 주는 학습 엔진도 없다.  
> 행렬, 벡터, 함수, 체인 룰, 상태 변경, 반복을 직접 연결하면서 신경망을 만든다.

Dense/Linear, Conv2D, Softmax, `NeuralNetwork`, `model.fit()` 같은 고수준 AI 기능은 기본 블록으로 제공하지 않습니다. 일반 수학 블록과 데이터 블록을 이용해 순전파, 손실 함수, 역전파, SGD, 미니배치, 평가 계산을 직접 구성합니다.

---

## 프로젝트 특징

### 수학 블록으로 신경망 직접 구성

한 층도 완성된 레이어 블록이 아니라 다음 수식을 직접 만듭니다.

```text
h = ReLU(Wx + b)
  = max(Wx + b, 0)
```

이를 여러 번 연결하면 예를 들어

```text
784 → 64 → 32 → 15
```

같은 다층 신경망을 구성할 수 있습니다.

활성화 함수, Softmax, Cross Entropy, 정확도 계산도 모두 일반 수학 블록의 조합으로 표현합니다.

### 자동미분을 사용하지 않는 역전파

이 프로젝트는 **계산 그래프를 보고 미분식을 자동 생성하거나 gradient를 자동으로 전파하지 않습니다.**

각 연산의 역전파는 사용자가 직접 정의합니다. 어떤 블록의 순전파가

```text
y = f(a, b)
```

라면 역전파 정의 편집기에는 자동으로 다음 값만 주어집니다.

```text
a                  순전파 입력값
b                  순전파 입력값
y                  순전파 출력값
g = ∂L/∂y          뒤에서 들어온 기울기
```

사용자는 이 값들을 기존 수학 블록에 직접 연결해

```text
∂L/∂a
∂L/∂b
```

를 계산하고, 어떤 계산 결과가 각 입력의 기울기인지 직접 지정합니다.

예를 들어

```text
y = a × b
```

의 역전파는

```text
∂L/∂a = g × b
∂L/∂b = g × a
```

를 `곱하기` 블록으로 직접 구성할 수 있습니다.

행렬과 벡터의 곱

```text
y = Wx
```

이라면

```text
∂L/∂W = g ⊗ x
∂L/∂x = Wᵀg
```

를 `외적`과 `전치 행렬 × 벡터`로 직접 구성할 수 있습니다.

프로그램이 하는 일은 **사용자가 만든 역전파 식에 현재 숫자·벡터·행렬 값을 넣어 계산하는 것뿐**입니다.

### 체인 룰의 실행 순서도 직접 구성

블록 인스턴스는 저장된 역전파 정의가 있으면 `순전파` 또는 `역전파 실행`으로 사용할 수 있습니다.

역전파 실행에서는:

1. 출력 쪽에서 들어올 기울기 변수 이름을 지정합니다.
2. 각 입력으로 보낼 기울기를 어느 변수에 저장할지 지정합니다.
3. 뒤쪽 블록부터 앞쪽 블록 순서로 직접 실행합니다.

예를 들어

```text
x → [A] → h → [B] → y → L
```

이라면 사용자가 직접

```text
g_y
 ↓
[B 역전파 실행]
 ↓ g_h
[A 역전파 실행]
 ↓ g_x
```

순서를 만듭니다.

프로그램은 `[B]` 다음에 `[A]`를 실행해야 한다는 사실을 계산 그래프에서 추론하지 않습니다. `둘 다 계산`과 `반복` 등을 이용해 사용자가 학습 순서를 명시합니다.

### 사용자 블록도 역전파를 한 번 정의해 재사용

여러 수학 블록을 하나의 사용자 블록으로 묶은 뒤, 그 사용자 블록 자체에 역전파 식을 따로 정의할 수 있습니다.

예를 들어

```text
LinearReLU(W, x, b) = max(Wx + b, 0)
```

를 사용자 블록으로 만들었다면 처음에는 내부 수학을 직접 구성하고 이해한 뒤, 역전파 정의에서

```text
g = ∂L/∂h

∂L/∂W = ...
∂L/∂x = ...
∂L/∂b = ...
```

를 한 번 직접 작성합니다.

그 뒤에는 `LinearReLU` 블록 한 개가 저장된 역전파 식을 한 번에 실행해 세 입력의 기울기를 계산할 수 있습니다.

즉 고수준 레이어를 처음부터 제공하는 것이 아니라, **사용자가 이미 이해하고 만든 수학을 스스로 추상화해서 재사용**합니다.

### 상태 변경과 반복

학습 과정 역시 블록으로 직접 구성합니다.

```text
gW = 직접 계산한 ∂L/∂W
W ← W - ηgW
```

학습용 핵심 블록:

- `값 바꾸기`
- `둘 다 계산`
- `반복`

미니배치 전용 블록도 없습니다. gradient를 직접 누적하고 평균낸 뒤 갱신합니다.

```text
G ← G + gW

15개 샘플 후
W ← W - η(G / 15)
G ← 0
```

중첩 반복으로 sample, batch, epoch 구조를 만들 수 있습니다.

## 역전파 정의 사용법

### 1. 순전파 식을 먼저 만든다

예를 들어

```text
z = wx + b
L = (z - y)²
```

를 기존 수학 블록으로 만듭니다.

### 2. 필요한 블록의 `역전파 직접 정의`를 연다

인스펙터에서 `역전파 직접 정의`를 누르면 같은 작업공간 UI가 임시 역전파 편집기로 바뀝니다.

왼쪽에는 해당 블록의

- 각 순전파 입력값
- 순전파 출력 `y`
- 뒤에서 들어오는 기울기 `g = ∂L/∂y`

가 고정 입력으로 표시됩니다.

### 3. 일반 수학 블록으로 미분식을 만든다

예를 들어 곱하기라면

```text
g × b

g × a
```

를 직접 만듭니다.

### 4. 각 입력의 기울기 출력을 지정한다

계산 결과 블록을 선택하고

```text
a의 기울기로 지정
b의 기울기로 지정
```

버튼을 누릅니다.

입력이 하나라면 출력도 하나, 입력이 세 개라면 기울기 출력도 세 개를 직접 정합니다.

### 5. 실제 학습 그래프에서 역전파를 실행한다

저장된 정의가 있는 블록의 `실행 방식`을 `역전파 실행`으로 바꿉니다.

그리고

```text
출력 기울기 변수 g     = 뒤에서 받은 gradient 변수 이름
입력 a 기울기 → 변수   = 앞쪽에 넘길 변수 이름
입력 b 기울기 → 변수   = 앞쪽에 넘길 변수 이름
```

을 지정합니다.

중간 gradient 변수는 바로 다음 역전파 블록에서 읽을 수 있도록 즉시 반영됩니다. 반면 실제 파라미터를 바꾸는 `값 바꾸기`는 기존처럼 반복 한 회차가 끝날 때 반영됩니다.

## 합성곱도 일반 수학 블록으로 구성

Conv2D 전용 블록은 제공하지 않습니다.

`슬라이딩 창 펼치기`는 2차원 배열에서 일정한 크기의 부분 배열을 차례로 꺼내 각 창을 한 줄로 펼칩니다. 예를 들어 28×28 입력에 3×3 창, stride 1, padding 0을 적용하면

```text
28×28
  ↓ 슬라이딩 창 펼치기 (3×3, stride 1)
676×9
```

이 됩니다.

3×3 커널을 길이 9 벡터 `k`로 두면 `행렬 × 벡터`로 모든 위치의 가중합을 한 번에 표현할 수 있습니다.

```text
그림값 28×28
  ↓
슬라이딩 창 펼치기
  ↓ 676×9
행렬 × 벡터 ← k ∈ R^9
  ↓ 676
배열 모양 바꾸기 (26,26)
  ↓
max(x, 0)
```

평균 풀링도 전용 Pooling 블록 없이 만들 수 있습니다. 예를 들어 26×26 배열을 2×2, stride 2로 펼치면 169×4 행렬이 되고, 여기에 `[0.25, 0.25, 0.25, 0.25]`를 곱하면 각 2×2 영역의 평균이 됩니다.

```text
26×26
  ↓ 슬라이딩 창 펼치기 (2×2, stride 2)
169×4
  ↓ 행렬 × 벡터 [1/4, 1/4, 1/4, 1/4]
169
  ↓ 배열 모양 바꾸기 (13,13)
13×13
```

역전파가 필요하다면 이 변환들의 미분 역시 사용자가 수학적으로 유도해 정의합니다. 프로그램이 convolution 또는 pooling의 gradient를 자동 생성하지 않습니다.

## Softmax와 Cross Entropy 직접 만들기

Softmax 전용 블록은 제공하지 않습니다.

안정화된 Softmax는 다음처럼 구성합니다.

```text
m = max(z)
shifted = z - m
e = exp(shifted)
p = e / sum(e)
```

즉

```text
p_i = exp(z_i - m) / Σ_j exp(z_j - m)
m = max(z)
```

입니다.

Cross Entropy 학습에서는 안정적인 log-softmax 형태를 사용할 수 있습니다.

```text
m = max(z)
logZ = m + log(sum(exp(z - m)))
logp = z - logZ
L = -sum(y * logp)
```

`log(softmax(z))`를 직접 계산하는 것보다 수치적으로 안정적입니다.

손실 함수의 미분 역시 자동으로 얻지 않고, 같은 방식으로 역전파 정의를 직접 구성합니다.

## 사용자 블록

여러 수학 블록을 선택해 하나의 **사용자 블록**으로 묶을 수 있습니다.

예를 들어

```text
행렬×벡터 → 더하기 → max(·,0)
```

를 설명한 뒤

```text
ReLU(Wx+b)
```

라는 하나의 사용자 블록으로 추상화할 수 있습니다.

사용자 블록은 다음 기능을 지원합니다.

- 내부 노드와 연결 구조 저장
- 필요한 외부 입력을 새 블록의 입력 포트로 유지
- 다른 계산에서 반복 사용
- 사용자 블록 자체의 수동 역전파 정의 저장
- 한 번 정의한 역전파를 여러 인스턴스에서 재사용
- 사용자 블록 안에 다른 사용자 블록 사용
- 사용하지 않는 사용자 블록 삭제
- 현재 작업공간, 다른 사용자 블록, 역전파 정의에서 참조 중인 블록의 실수 삭제 방지

### 내부 구조 편집

작업공간의 사용자 블록을 선택하고 `내부 구조 편집`을 누르면 **평소 사용하던 바로 그 작업공간이 해당 블록의 내부 그래프로 전환**됩니다.

따라서 내부에서도 일반 작업과 동일하게

- 노드 이동
- pan / zoom
- 포트 연결 변경
- 새 수학 블록 추가
- 내부 블록 삭제
- 블록 설정 수정
- 추가 블록 묶기

를 사용할 수 있습니다.

외부에서 들어오는 사용자 블록 입력은 내부 작업공간에서 `외부 입력` 노드로 표시됩니다. 원하는 내부 노드를 사용자 블록의 최종 출력으로 지정할 수 있습니다.

사용자 블록은 순수한 재사용 함수이므로 `값 바꾸기`와 `반복` 같은 실행 제어는 내부에 넣지 않습니다.

### 사용자 블록 실행

사용자 블록의 순전파는 내부 그래프를 한 번 분석해 평평한 실행 계획으로 컴파일합니다.

역전파는 내부 순전파 그래프를 프로그램이 다시 미분하는 방식이 아닙니다. 사용자 블록에 별도로 저장된 **사용자 작성 역전파 그래프**를 실행합니다.

즉 블록 묶기는 수학적 의미를 바꾸는 기능이 아니라 **이미 이해한 구조를 함수처럼 추상화하는 기능**입니다.

## 작업공간

- 마우스 / 터치로 노드 이동
- 출력 포트 → 입력 포트 연결
- 연결선 끊기
- 빈 공간 드래그로 pan
- 터치 핀치 확대·축소
- PC `Ctrl + wheel` / 트랙패드 핀치 확대·축소
- `− / 100% / +` 확대·축소 버튼
- 화면 위치와 배율 초기화
- 선택한 블록의 수학식과 현재 값 확인
- 블록 묶기
- 사용자 블록 내부 구조 편집
- 블록/사용자 블록의 수동 역전파 정의 편집
- 선택 계산
- 긴 반복의 진행률과 `step/s` 표시
- 반복 횟수 최대 `1,000,000`

예시:

```text
반복 12,436 / 50,000 · 24.9% · 속도 1,760 step/s · epoch 3/10 · i 2436/5000
```

### 연결선 끊기

| 방법 | 동작 |
| --- | --- |
| 연결선 누르기 | 첫 번째 누름은 선을 선택하고, 한 번 더 누르면 끊습니다 |

인스펙터의 `연결된 입력` 목록에도 입력별 `연결 끊기` 버튼이 있습니다.

## 자동 저장과 새로고침 복구

편집 중인 작업공간은 브라우저 `localStorage`에 자동 저장됩니다.

자동 저장 대상:

- 노드와 연결
- 노드 위치
- 블록 설정값
- 사용자 블록 정의
- 수동 역전파 정의
- 선택한 Quick Draw 종류
- 작업공간 pan / zoom 상태

새로고침하면 직전 편집 상태를 자동 복구합니다.

사용자 블록 내부 또는 역전파 정의를 편집 중일 때는 임시 내부 그래프가 일반 작업공간 자동저장을 덮어쓰지 않도록 자동저장을 잠시 멈춥니다.

### 자동 저장하지 않는 것

**학습된 가중치와 런타임 변수 값은 자동 저장하지 않습니다.**

즉 새로고침 시 그래프 구조와 편집 상태는 돌아오지만, 학습 중 변경된 `W`, `b`, gradient 누적 변수 등은 초기 상태에서 다시 시작합니다.

학습된 값을 보존하려면 `.mmlweights` 또는 `.mmlab` 저장 기능을 사용합니다.

## Quick Draw 데이터

Google Quick, Draw! 데이터 15종을 사용합니다.

- airplane
- apple
- bicycle
- car
- cat
- clock
- cup
- face
- fish
- flower
- guitar
- house
- star
- tree
- umbrella

각 종류는 28×28 grayscale 그림 10,000장입니다.

`data/<class>.bin` 파일 하나의 크기:

```text
10,000 × 28 × 28 = 7,840,000 bytes
```

필요한 종류만 선택해 메모리에 불러옵니다.

### 반복 번호와 데이터 매핑

예를 들어 로드된 클래스가

```text
cat, fish, house, tree, car
```

순서라면

```text
i=0 → cat #0
i=1 → fish #0
i=2 → house #0
i=3 → tree #0
i=4 → car #0
i=5 → cat #1
```

처럼 클래스가 번갈아 나오도록 매핑됩니다.

따라서 15종을 로드했을 때 연속된 15개 샘플은 각 클래스 하나씩으로 구성되어 균형 잡힌 미니배치를 만들기 쉽습니다.

데이터 출처:

- Google Quick, Draw! Dataset: https://quickdraw.withgoogle.com/data
- Dataset repository: https://github.com/googlecreativelab/quickdraw-dataset

## 평가도 수학 블록으로 구성

별도의 `Model.evaluate()`나 완성된 정확도 블록은 없습니다.

확률 벡터를 `p`, 정답 one-hot을 `y`라고 하면 다음처럼 구성할 수 있습니다.

```text
m = max(p)
mask = [p = m]
predict = mask / sum(mask)
hit = y · predict
```

전체 테스트에서는

```text
correct ← correct + hit
accuracy = correct / test_count
```

를 사용합니다.

## 선택 계산과 손그림 테스트

### 선택 계산

작업공간 전체가 아니라 **선택한 블록과 그 조상 그래프만 실행**할 수 있습니다.

학습 그래프와 테스트 그래프를 같은 작업공간에 만들어도 테스트 출력만 선택하면 학습 반복을 다시 돌리지 않고 평가 부분만 실행할 수 있습니다.

반복의 hot path는 미리 분석한 실행 계획을 재사용합니다.

### 손그림 테스트

오른쪽 그림판에 직접 그림을 그리고 학습된 모델의 최종 점수 / 확률 출력 블록을 선택해 테스트할 수 있습니다.

손그림은 Quick Draw 입력 분포에 가깝도록 28×28로 전처리된 뒤 선택한 예측 그래프에 입력됩니다.

추론에서는 학습용 `반복`과 `값 바꾸기` 경로를 실행하지 않도록 예측 출력만 선택합니다.

## 저장 형식

### `.mmlab` — 전체 프로젝트

상단 `내보내기` / `불러오기` 기능을 사용합니다.

저장 항목:

- 그래프 노드와 연결
- 노드 위치와 파라미터
- 사용자 블록 정의
- 수동 역전파 정의
- 런타임 변수 값(학습된 가중치 포함)
- 데이터셋 선택
- 작업공간 pan / zoom

Quick Draw 이미지 원본 바이트는 포함하지 않습니다.

### `.mmlweights` — 학습 파라미터

학습된 파라미터만 따로 저장합니다.

불러올 때 변수 이름, 배열 모양, 데이터 클래스 순서를 확인합니다.

## 실행 성능 최적화

이 프로젝트는 사용자가 만든 수학과 계산 순서를 바꾸지 않고 반복 실행 오버헤드를 줄이는 방향으로 최적화합니다.

주요 최적화:

- 그래프 입력 연결과 topological order 캐시
- 반복 hot path 컴파일
- 원소별 연산 전용 `Float32Array` 커널
- 행렬 연산 전용 빠른 경로
- 결과 버퍼 arena 재사용
- 불필요한 runtime 배열 복사 감소
- 사용자 블록 순전파 실행 계획 컴파일

역전파에 대한 최적화 원칙도 같습니다.

> 프로그램이 더 영리하게 미분하는 것이 아니라, 사용자가 작성한 같은 역전파 식을 더 적은 탐색·할당으로 실행한다.

---

## 의도적으로 제공하지 않는 것

이 프로젝트는 완성된 AI 모델을 제공하는 도구가 아니라 **AI를 이루는 수학을 직접 조립하는 도구**를 목표로 합니다.

따라서 다음 기능은 기본 블록으로 제공하지 않습니다.

- `NeuralNetwork` 클래스
- Dense / Linear 완성 레이어
- Conv2D / Pooling 완성 레이어
- Softmax 전용 AI 블록
- 완성된 모델 구조
- 자동미분 엔진
- 미분 한 번으로 전체 gradient를 계산하는 블록
- 한 번 누르면 모델 전체를 만들어 주는 학습 버튼
- 모델 전용 정확도 / 평가 블록
- 미니배치 전용 블록

필요한 구조는 행렬, 벡터, 일반 연산, 배열 변환, **사용자가 정의한 체인 룰**, 상태 변경, 반복, 사용자 블록으로 직접 만듭니다.

## 코드 구조

JavaScript는 모두 `js/` 아래에 있고, `index.html`이 읽는 순서가 곧 의존 순서입니다.

| 파일 | 역할 |
| --- | --- |
| `hooks.js` | 인스펙터와 진단 기능을 위한 확장 지점 |
| `state.js` | DOM 핸들, Quick Draw 종류 표, 공용 상태 |
| `values.js` | 값 모델, 원소별·행렬 커널, 결과 버퍼 arena |
| `runtime-variables.js` | 상태를 가지는 `변수`와 반복 번호 스택 |
| `spatial-ops.js` | 배열 모양 변환과 슬라이딩 창 연산 |
| `blocks.js` | 기본 수학 블록 카탈로그 |
| `graph-cache.js` | 그래프 구조와 topological order 캐시 |
| `user-block-forward.js` | 사용자 블록의 forward-only 실행 계획 컴파일 |
| `evaluate*.js` | 그래프 계산, 반복 실행, 진행 표시 |
| `workspace-ui.js` / `viewport.js` | 블록·연결선·인스펙터 / 이동·확대·드래그 |
| `user-blocks.js` | 묶기, 내 블록 팔레트, 내부 구조 편집 |
| `manual-backprop.js` | 사용자가 직접 만드는 블록/사용자 블록 역전파 정의와 실행 |
| `dataset.js` / `drawing.js` | Quick Draw 로딩 / 그림판과 손그림 테스트 |
| `selected-evaluation.js` | 선택 계산과 결과 표시 |
| `file-io.js` / `autosave.js` | `.mmlab`·`.mmlweights` / 자동 저장 |
| `profiler.js` | 진단 전용. 없어도 계산 결과는 같습니다 |
| `boot.js` | 버튼 연결과 시작 순서 |

자동미분 실행 파일(`autodiff.js`, `autodiff-compiled.js`, `autodiff-spatial-fusion.js`)은 사용하지 않습니다.

## 실행

정적 HTML / CSS / JavaScript 프로젝트입니다.

```bash
python -m http.server 8000
```

그 뒤 브라우저에서

```text
http://localhost:8000
```

으로 접속합니다.

개발 중 오래된 JavaScript가 브라우저 캐시에 남는 것을 막기 위해 `index.html`의 정적 파일 URL에 공통 버전 쿼리를 붙여 사용합니다.
