# Quick Draw 수학 신경망 발표 도구

현재 1단계 구현:

- 마우스/터치 그림판
- 그림의 잉크 영역 자동 탐지
- 28×28 중앙 정렬 및 축소
- 0~1 범위의 784차원 벡터 변환
- 28×28 픽셀 미리보기
- 신경망 코어 클래스 골격

## 실행

`index.html`을 브라우저에서 직접 열어도 현재 기능은 동작합니다.

로컬 서버를 쓰려면 폴더에서:

```bash
python -m http.server 8000
```

후 브라우저에서 `http://localhost:8000` 접속.
