# Machine Learning Math Project

수학 동아리 개인 심화 탐구 발표를 위해 만든 **블록형 수학·머신러닝 실험 도구**입니다.

핵심 목표는 완성된 신경망을 가져다 쓰는 것이 아니라, **신경망을 이루는 수학을 직접 조립해서 실제 학습까지 수행하는 것**입니다.

> 발표 시작 시점에는 완성된 신경망이 없다.  
> 행렬, 벡터, 함수, 상태 변경, 반복을 직접 연결하면서 신경망과 역전파를 만든다.

Dense/Linear, Conv2D, Softmax, `NeuralNetwork`, `model.fit()` 같은 고수준 AI 기능은 기본 블록으로 제공하지 않습니다. 대신 일반 수학 블록과 데이터 블록을 이용해 순전파, 손실 함수, 역전파, SGD, 미니배치, 평가 계산을 직접 구성합니다.

## 프로젝트 특징

### 수학 블록으로 신경망 직접 구성

한 층도 완성된 레이어 블록이 아니라 다음 수식을 직접 만듭니다.

```text
h = ReLU(Wx + b)
  = max(Wx + b, 0)
```

이를 여러 번 연결하면 예를 들어

```text
784 → 64 → 32 → 15
```

같은 다층 신경망을 구성할 수 있습니다.

활성화 함수, Softmax, Cross Entropy, 정확도 계산도 모두 일반 수학 블록의 조합으로 표현합니다.

### 수동 역전파

자동미분은 사용하지 않습니다.

각 연산의 역전파 식은 사용자가 직접 정의합니다. 정의 편집기에서는 해당 블록의

- 순전파 입력값
- 순전파 출력값 `y`
- 뒤에서 들어오는 기울기 `g = ∂L/∂y`

를 사용할 수 있습니다.

예를 들어 `y = a × b`라면 사용자가 직접

```text
∂L/∂a = g × b
∂L/∂b = g × a
```

를 일반 수학 블록으로 만듭니다.

프로그램은 계산 그래프를 보고 체인 룰을 자동 적용하지 않고, 역전파 실행 순서도 자동으로 정하지 않습니다. 사용자가 뒤쪽 연산부터 직접 실행 순서를 구성합니다.

저장된 수동 역전파 정의는 실행 시 한 번 평평한 실행 계획으로 컴파일됩니다. 반복 학습 중에는 같은 정의를 다시 분석하지 않고 실행 계획과 scratch 배열을 재사용합니다. 순전파 출력 `y`를 실제로 사용하지 않는 역전파 식이라면 소유 블록의 순전파도 불필요하게 다시 계산하지 않습니다.

### 사용자 블록의 역전파 재사용

여러 순전파 연산을 사용자 블록으로 묶은 뒤, 그 사용자 블록 자체에도 별도의 역전파 정의를 저장할 수 있습니다.

한 번 유도하고 정의한 뒤에는 접힌 사용자 블록 하나가 `g`를 받아 각 외부 입력의 기울기를 한 번에 계산할 수 있습니다.

즉 고수준 레이어를 처음부터 제공하는 것이 아니라, **직접 이해하고 만든 수학 구조를 사용자가 스스로 추상화**합니다.

현재 실행기는 사용자 블록을 단순한 UI 묶음으로만 취급하지 않습니다. 반복 학습 중에는 내부 실행 계획을 컴파일하고, 같은 step 안에서 동일한 부분식이 동일한 입력을 받을 경우 결과를 재사용합니다. 순전파에서 이미 계산한 사용자 블록 내부값과 수동 역전파 정의의 부분식이 같다면 그 중간값도 재사용할 수 있습니다.

이 최적화는 미분식을 추론하거나 자동으로 생성하는 기능이 아닙니다. **사용자가 작성한 수학식의 의미는 그대로 두고 중복 계산만 제거합니다.**

### 상태 변경과 반복

학습 과정 역시 블록으로 직접 구성합니다.

```text
gW = 직접 구성한 역전파 식
W ← W - ηgW
```

학습용 핵심 블록:

- `값 바꾸기`
- `둘 다 계산`
- `반복`

미니배치 전용 블록도 없습니다. gradient를 직접 누적하고 평균낸 뒤 갱신합니다.

```text
G ← G + gW

15개 샘플 후
W ← W - η(G / 15)
G ← 0
```

중첩 반복으로 sample, batch, epoch 구조를 만들 수 있습니다.

## 합성곱도 일반 수학 블록으로 구성

Conv2D 전용 블록은 제공하지 않습니다.

`슬라이딩 창 펼치기`는 2차원 배열에서 일정한 크기의 부분 배열을 차례로 꺼내 각 창을 한 줄로 펼칩니다. 예를 들어 28×28 입력에 3×3 창, stride 1, padding 0을 적용하면

```text
28×28
  ↓ 슬라이딩 창 펼치기 (3×3, stride 1)
676×9
```

이 됩니다.

3×3 커널을 길이 9 벡터 `k`로 두면 이미 있는 `행렬 × 벡터`로 모든 위치의 가중합을 한 번에 표현할 수 있습니다.

```text
그림값 28×28
  ↓
슬라이딩 창 펼치기
  ↓ 676×9
행렬 × 벡터 ← k ∈ R^9
  ↓ 676
배열 모양 바꾸기 (26,26)
  ↓
max(x, 0)
```

즉 완성된 합성곱 레이어를 호출하지 않고도

```text
지역 3×3 값 추출 → 커널과 내적 → 공간 모양 복원 → 활성화
```

과정을 직접 조립할 수 있습니다.

평균 풀링도 전용 Pooling 블록 없이 만들 수 있습니다. 예를 들어 26×26 배열을 2×2, stride 2로 펼치면 169×4 행렬이 되고, 여기에 `[0.25, 0.25, 0.25, 0.25]`를 곱하면 각 2×2 영역의 평균이 됩니다.

```text
26×26
  ↓ 슬라이딩 창 펼치기 (2×2, stride 2)
169×4
  ↓ 행렬 × 벡터 [1/4, 1/4, 1/4, 1/4]
169
```

수동 역전파에서는 반대로 pooled gradient를 네 위치에 `1/4`씩 나눈 뒤 `슬라이딩 창 합치기`로 26×26 위치에 되돌릴 수 있습니다.

## Softmax와 Cross Entropy 직접 만들기

Softmax 전용 블록은 제공하지 않습니다.

안정화된 Softmax는 다음처럼 구성합니다.

```text
m = max(z)
shifted = z - m
e = exp(shifted)
p = e / sum(e)
```

Cross Entropy 학습에서는 안정적인 log-softmax 형태를 사용할 수 있습니다.

```text
m = max(z)
logZ = m + log(sum(exp(z - m)))
logp = z - logZ
L = -sum(y * logp)
```

역전파 역시 결과 공식을 직접 유도해 일반 블록으로 만들 수 있습니다. one-hot 정답에서는 최종 logits의 기울기가

```text
∂L/∂z = softmax(z) - y
```

가 되므로, 이 식부터 뒤쪽 레이어 방향으로 직접 역전파를 구성할 수 있습니다.

## 사용자 블록

여러 수학 블록을 선택해 하나의 **사용자 블록**으로 묶을 수 있습니다.

예를 들어

```text
행렬×벡터 → 더하기 → max(·,0)
```

를 설명한 뒤

```text
ReLU(Wx+b)
```

라는 하나의 사용자 블록으로 추상화할 수 있습니다.

사용자 블록은 다음 기능을 지원합니다.

- 내부 노드와 연결 구조 저장
- 필요한 외부 입력을 새 블록의 입력 포트로 유지
- 다른 계산에서 반복 사용
- 별도로 직접 작성한 역전파 정의 저장
- 사용자 블록 안에 다른 사용자 블록 사용
- 사용하지 않는 사용자 블록 삭제
- 현재 작업공간, 다른 사용자 블록, 역전파 정의에서 참조 중인 블록의 실수 삭제 방지

### 내부 구조 편집

사용자 블록을 선택하고 **내부 블록 복사**를 누르면 그 안의 노드와 연결이 현재
작업공간에 복사됩니다. 원래 블록에 연결된 외부 입력도 복사본에 이어지며, 원본
블록과 기존 출력 연결은 그대로 유지됩니다. 복사된 노드의 설정은 독립적으로
수정할 수 있습니다. 내부에 또 다른 사용자 블록이 있으면 그 블록은 접힌 채로
같은 정의를 참조합니다. 필요하면 해당 블록에서도 내부 복사를 실행하세요.

내부 편집 중에는 **저장하고 바깥으로 복사**로 편집한 내용을 저장한 뒤 복사할 수
있습니다. 원래 외부 입력이 미연결이었다면 복사본에서도 그 입력을 직접 연결해야
합니다. 복사 후에는 복사된 노드가 보이도록 화면이 이동합니다.

작업공간의 사용자 블록을 선택하고 `내부 구조 편집`을 누르면 평소 사용하던 작업공간이 해당 블록의 내부 그래프로 전환됩니다.

내부에서도 일반 작업과 동일하게 노드 이동, pan/zoom, 연결 변경, 블록 추가/삭제, 설정 수정, 추가 묶기를 사용할 수 있습니다.

내부 편집에는 다음 제한이 있습니다.

- 편집 중인 블록 자신, 그리고 그 블록을 사용하는 다른 사용자 블록은 내부에 넣을 수 없습니다. 순환 참조가 생기면 계산이 무한히 반복됩니다.
- 변수 블록은 내부에 넣을 수 없습니다. 사용자 블록은 입력 포트만 받는 순수 함수이므로, 변수는 바깥에 두고 외부 입력으로 연결합니다. 묶기도 같은 규칙으로 변수를 바깥에 남깁니다.
- 미분, 값 바꾸기, 반복 블록은 실행 제어 블록이라 내부에 넣을 수 없습니다.
- 내부에서 추가 묶기를 하면 새로 만들어진 블록이 기존 출력 블록의 자리를 그대로 이어받습니다.

저장하면 그 블록을 사용하는 다른 사용자 블록과 역전파 정의의 실행 계획도 함께 다시 만들어지므로, 중첩된 블록을 고쳐도 바깥 블록이 옛 정의를 계속 쓰는 일은 없습니다.

### 역전파 정의 편집

일반 연산이나 사용자 블록을 선택하면 `역전파 직접 정의`를 열 수 있습니다.

편집기에는 원래 입력값, 순전파 출력 `y`, 출력에서 들어오는 gradient `g`가 소스로 나타납니다. 각 입력에 대해 어떤 계산 결과를 gradient로 보낼지 사용자가 직접 지정합니다.

정의가 저장된 블록 인스턴스는 `순전파` / `역전파 실행`을 선택할 수 있습니다. 역전파 실행 시 어떤 gradient 변수를 읽고 각 입력 gradient를 어떤 변수에 기록할지 직접 지정합니다.

실제 저장 대상 이름이 비어 있는 입력 gradient는 학습 hot path에서 해당 계산 가지 자체를 실행하지 않습니다. 예를 들어 이미지 입력의 gradient가 이후 어디에도 쓰이지 않는다면 그 가지를 생략할 수 있습니다.

## 현재 CNN 실험 구조

현재 Quick Draw 15종 실험에서는 일반 수학 블록을 먼저 구성한 뒤 다음과 같은 사용자 블록으로 묶어 사용하고 있습니다.

```text
Conv 3×3 + ReLU + AvgPool
        × 4분기
          ↓
4분기 Dense + ReLU (64)
          ↓
Dense + ReLU (32)
          ↓
Dense (15)
          ↓
Softmax Cross Entropy
```

합성곱, 평균 풀링, Dense, Softmax Cross Entropy 모두 내부적으로는 이 프로젝트의 일반 수학 블록 조합이며, 각 학습용 사용자 블록의 역전파도 직접 작성한 수학 그래프로 저장되어 있습니다.

현재 실험 설정 예시는 다음과 같습니다.

```text
클래스: 15종
각 클래스: 10,000장
미니배치: 15
batch / epoch: 5,000
학습 epoch: 5
```

따라서 한 epoch에서

```text
15 × 5,000 = 75,000 samples
```

을 사용하며, 전체 150,000장 기준으로 한 epoch에 데이터의 절반에 해당하는 샘플 수를 봅니다. 총 파라미터 업데이트 횟수는 `5,000 × 5 = 25,000`회입니다.

이 값은 프로그램에 고정된 설정이 아니라 작업공간의 `반복` 블록에서 자유롭게 바꿀 수 있습니다.

- 출력 포트 → 입력 포트 연결

- PC `Ctrl + wheel` / 트랙패드 핀치 확대·축소
- `− / 100% / +` 확대·축소 버튼
- 화면 위치와 배율 초기화
- 선택한 블록의 수학식과 현재 값 확인
- 블록 묶기
- 수동 역전파 정의 편집
- 선택 계산
- 긴 반복의 진행률과 `step/s` 표시
- 반복 횟수 최대 `1,000,000`

`반복` 블록을 선택하면 오른쪽 인스펙터의 `반복 횟수`에서 학습 batch 수나 epoch 수 같은 반복 횟수를 직접 조절할 수 있습니다. 별도의 학습 횟수 전용 숫자 블록은 없습니다.

---

## 학습 계산 프로파일러

자동미분 제거 이후 학습 프로파일러도 수동 역전파 구조에 맞게 다시 구성했습니다.

학습 중 **컴파일된 leaf 반복 1회**를 하나의 step으로 보고 64 step마다 상세 샘플을 기록합니다.

표시 항목:

- 전체 벽시계 `ms/step`
- 대략적인 `step/s`
- 샘플 반복 실행 시간
- 노드 실행 시간 합
- step 내부 기타 비용
- 반복 제어 / 상태 반영 / UI 등의 비용
- 핵심 수치 커널별 시간
- 느린 블록 종류
- 느린 개별 블록

자동미분 시절의 `gradient 전체`, `gradient backward VJP` 같은 항목은 더 이상 사용하지 않습니다. 순전파와 역전파 모두 사용자가 구성한 일반 수학 그래프이므로 실제 실행된 노드를 기준으로 측정합니다.

## 자동 저장과 새로고침 복구

편집 중인 작업공간은 브라우저 `localStorage`에 자동 저장됩니다.

자동 저장 대상:

- 노드와 연결
- 노드 위치
- 블록 설정값
- 사용자 블록 정의
- 수동 역전파 정의
- 선택한 Quick Draw 종류
- 작업공간 pan / zoom 상태

학습된 가중치와 런타임 변수 값은 자동 저장하지 않습니다. 보존하려면 `.mmlweights` 또는 `.mmlab`을 사용합니다.

## 평가도 수학 블록으로 구성

별도의 `Model.evaluate()`나 완성된 정확도 블록은 없습니다.

확률 벡터를 `p`, 정답 one-hot을 `y`라고 하면 다음처럼 구성할 수 있습니다.

```text
m = max(p)
mask = [p = m]
predict = mask / sum(mask)
hit = y · predict
```

전체 테스트에서는

```text
correct ← correct + hit
accuracy = correct / test_count
```

를 사용합니다.

## 저장 형식

### `.mmlab` — 전체 프로젝트

저장 항목:

- 그래프 노드와 연결

- 수동 역전파 정의

- 데이터셋 선택

### `.mmlweights` — 학습 파라미터

## 실행 성능 최적화

수학 그래프의 의미를 바꾸지 않고 반복 실행 오버헤드와 중복 계산을 줄이는 방향으로 최적화합니다.

- 그래프 입력 연결과 topological order 캐시
- 반복 실행 hot path 컴파일
- 원소별 연산 전용 `Float32Array` 커널
- 행렬 연산 전용 빠른 경로
- 결과 버퍼 arena 재사용
- 사용자 블록 순전파 실행 계획 컴파일
- 수동 역전파 실행 계획 컴파일 및 scratch 배열 재사용
- 역전파가 `y`를 사용하지 않을 때 불필요한 owner forward 생략
- gradient 변수 이름 → 변수 블록 lookup 캐시
- 변수 signature 재계산 제거(파라미터가 바뀔 때만 다시 만듦)
- 역전파 블록 인스턴스별 gradient 목적지·실행 계획 캐시
- 사용자 블록 내부 공통 부분식 재사용
- 순전파 내부값과 역전파 수식의 공통 중간값 재사용
- 실제 저장하지 않는 gradient 출력 가지 제거

이 최적화는 자동미분이나 미분식 자동 생성이 아닙니다. 사용자가 작성한 수학 그래프와 역전파 순서를 그대로 유지하면서, 이미 계산한 것과 완전히 같은 계산만 다시 하지 않는 방식입니다.

역전파 블록 한 번 호출에 붙어 있던 고정 비용은 약 `1,830 ns`에서 약 `490 ns`로 줄었습니다. 같은 학습 그래프의 가중치 체크섬은 비트 단위로 동일합니다.

`bench/train-bench.mjs`가 이 체크섬을 검사합니다. 오버헤드만 줄이는 최적화라면 체크섬이 절대 바뀌면 안 됩니다.

## 의도적으로 제공하지 않는 것

- `NeuralNetwork` 클래스
- Dense / Linear 완성 레이어
- Conv2D / Pooling 완성 레이어
- Softmax 전용 AI 블록
- 자동미분
- 완성된 모델 구조
- 한 번 누르면 모델 전체를 만들어 주는 학습 버튼
- 모델 전용 정확도 / 평가 블록
- 미니배치 전용 블록

필요한 구조는 행렬, 벡터, 일반 연산, 배열 변환, 상태 변경, 반복, 사용자 블록, 사용자가 직접 작성한 역전파 식으로 만듭니다.
