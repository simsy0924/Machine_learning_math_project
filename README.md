# Machine Learning Math Project

수학 동아리 개인 심화 탐구 발표를 위해 만든 **블록형 수학·머신러닝 실험 도구**입니다.

핵심 목표는 완성된 신경망을 가져다 쓰는 것이 아니라, **신경망을 이루는 수학을 직접 조립해서 실제 학습까지 수행하는 것**입니다.

> 발표 시작 시점에는 완성된 신경망이 없다.  
> 행렬, 벡터, 함수, 미분, 상태 변경, 반복을 직접 연결하면서 신경망을 만든다.

Dense/Linear, Conv2D, Softmax, `NeuralNetwork`, `model.fit()` 같은 고수준 AI 기능은 기본 블록으로 제공하지 않습니다. 대신 일반 수학 블록과 데이터 블록을 이용해 순전파, 손실 함수, 역전파, SGD, 미니배치, 평가 계산을 직접 구성합니다.

---

## 프로젝트 특징

### 수학 블록으로 신경망 직접 구성

한 층도 완성된 레이어 블록이 아니라 다음 수식을 직접 만듭니다.

```text
h = ReLU(Wx + b)
  = max(Wx + b, 0)
```

이를 여러 번 연결하면 예를 들어

```text
784 → 64 → 32 → 15
```

같은 다층 신경망을 구성할 수 있습니다.

활성화 함수, Softmax, Cross Entropy, 정확도 계산도 모두 일반 수학 블록의 조합으로 표현합니다.

### 자동미분과 역전파

연결된 스칼라 손실식을 원하는 변수에 대해 미분할 수 있습니다.

```text
∂L/∂W
∂L/∂b
```

내부적으로 reverse-mode automatic differentiation을 사용하며 스칼라, 벡터, 행렬과 사용자 블록을 통과하는 gradient를 계산합니다.

같은 loss에서 여러 파라미터의 미분을 요청하면 순전파와 역전파를 공유해 중복 계산을 줄입니다.

### 상태 변경과 반복

학습 과정 역시 블록으로 직접 구성합니다.

```text
g = ∂L/∂W
W ← W - ηg
```

학습용 핵심 블록:

- `값 바꾸기`
- `둘 다 계산`
- `반복`

미니배치 전용 블록도 없습니다. gradient를 직접 누적하고 평균낸 뒤 갱신합니다.

```text
G ← G + ∂L/∂W

15개 샘플 후
W ← W - η(G / 15)
G ← 0
```

중첩 반복으로 sample, batch, epoch 구조를 만들 수 있습니다.

## 합성곱도 일반 수학 블록으로 구성

Conv2D 전용 블록은 제공하지 않습니다.

`슬라이딩 창 펼치기`는 2차원 배열에서 일정한 크기의 부분 배열을 차례로 꺼내 각 창을 한 줄로 펼칩니다. 예를 들어 28×28 입력에 3×3 창, stride 1, padding 0을 적용하면

```text
28×28
  ↓ 슬라이딩 창 펼치기 (3×3, stride 1)
676×9
```

이 됩니다.

3×3 커널을 길이 9 벡터 `k`로 두면 이미 있는 `행렬 × 벡터`로 모든 위치의 가중합을 한 번에 표현할 수 있습니다.

```text
그림값 28×28
  ↓
슬라이딩 창 펼치기
  ↓ 676×9
행렬 × 벡터 ← k ∈ R^9
  ↓ 676
배열 모양 바꾸기 (26,26)
  ↓
max(x, 0)
```

즉 완성된 합성곱 레이어를 호출하지 않고도

```text
지역 3×3 값 추출 → 커널과 내적 → 공간 모양 복원 → 활성화
```

과정을 직접 조립할 수 있습니다.

`슬라이딩 창 펼치기`는 창 높이/너비, 세로/가로 stride, zero padding을 설정할 수 있습니다.

평균 풀링도 전용 Pooling 블록 없이 만들 수 있습니다. 예를 들어 26×26 배열을 2×2, stride 2로 펼치면 169×4 행렬이 되고, 여기에 `[0.25, 0.25, 0.25, 0.25]`를 곱하면 각 2×2 영역의 평균이 됩니다.

```text
26×26
  ↓ 슬라이딩 창 펼치기 (2×2, stride 2)
169×4
  ↓ 행렬 × 벡터 [1/4, 1/4, 1/4, 1/4]
169
  ↓ 배열 모양 바꾸기 (13,13)
13×13
```

두 변환 모두 자동미분을 통과합니다. `배열 모양 바꾸기`는 gradient의 원소 순서를 유지한 채 원래 모양으로 되돌리고, `슬라이딩 창 펼치기`는 여러 창에 중복되어 들어간 같은 픽셀의 gradient를 원래 위치에 합산합니다.

따라서 커널 파라미터뿐 아니라 합성곱 앞쪽의 입력이나 이전 층까지 gradient를 전달할 수 있습니다.

## Softmax와 Cross Entropy 직접 만들기

Softmax 전용 블록은 제공하지 않습니다.

안정화된 Softmax는 다음처럼 구성합니다.

```text
m = max(z)
shifted = z - m
e = exp(shifted)
p = e / sum(e)
```

즉

```text
p_i = exp(z_i - m) / Σ_j exp(z_j - m)
m = max(z)
```

입니다.

Cross Entropy 학습에서는 안정적인 log-softmax 형태를 사용할 수 있습니다.

```text
m = max(z)
logZ = m + log(sum(exp(z - m)))
logp = z - logZ
L = -sum(y * logp)
```

`log(softmax(z))`를 직접 계산하는 것보다 수치적으로 안정적입니다.

## 사용자 블록

여러 수학 블록을 선택해 하나의 **사용자 블록**으로 묶을 수 있습니다.

예를 들어

```text
행렬×벡터 → 더하기 → max(·,0)
```

를 설명한 뒤

```text
ReLU(Wx+b)
```

라는 하나의 사용자 블록으로 추상화할 수 있습니다.

사용자 블록은 다음 기능을 지원합니다.

- 내부 노드와 연결 구조 저장
- 필요한 외부 입력을 새 블록의 입력 포트로 유지
- 다른 계산에서 반복 사용
- 사용자 블록을 통과하는 자동미분
- 사용자 블록 안에 다른 사용자 블록 사용
- 사용하지 않는 사용자 블록 삭제
- 현재 작업공간이나 다른 사용자 블록에서 참조 중인 블록의 실수 삭제 방지

### 내부 구조 편집

사용자 블록은 별도의 단순화된 그림으로 보여주지 않습니다.

작업공간의 사용자 블록을 선택하고 `내부 구조 편집`을 누르면 **평소 사용하던 바로 그 작업공간이 해당 블록의 내부 그래프로 전환**됩니다.

따라서 내부에서도 일반 작업과 동일하게

- 노드 이동
- pan / zoom
- 포트 연결 변경
- 새 수학 블록 추가
- 내부 블록 삭제
- 블록 설정 수정
- 추가 블록 묶기

를 사용할 수 있습니다.

외부에서 들어오는 사용자 블록 입력은 내부 작업공간에서 `외부 입력` 노드로 표시됩니다. 이 노드는 사용자 블록의 공개 입력 포트를 뜻하며 연결 대상과 이름을 편집할 수 있습니다.

원하는 내부 노드를 선택해 **사용자 블록의 최종 출력으로 지정**할 수도 있습니다.

편집이 끝나면:

- `저장하고 돌아가기` — 변경한 정의를 저장하고 원래 작업공간으로 복귀
- `취소` — 내부 변경을 버리고 원래 작업공간으로 복귀

합니다.

사용자 블록은 순수한 재사용 수학 함수로 동작해야 하므로 `미분`, `값 바꾸기`, `반복`은 내부에 넣지 않습니다. 이 블록들은 사용자 블록 바깥에서 사용합니다.

### 사용자 블록 실행 최적화

블록을 묶었다고 학습 속도가 크게 떨어지지 않도록 사용자 블록 내부도 컴파일합니다.

각 정의에 대해 최초 한 번만 다음 정보를 준비합니다.

- topological order
- 내부 입력 연결
- forward 실행 계획
- backward 실행 계획

자동미분에서는 사용자 블록의 forward에서 계산한 내부 값을 tape에 보관하고 VJP가 그대로 재사용합니다. 따라서 역전파를 위해 내부 forward를 다시 반복하는 비용을 줄입니다.

즉 블록 묶기는 **수학적 의미를 바꾸는 기능이 아니라 이미 이해한 구조를 함수처럼 추상화하는 기능**입니다.

`작업공간 초기화` 버튼은 실수로 전체 그래프를 지우지 않도록 확인창을 한 번 더 표시합니다.

## 자동 저장과 새로고침 복구

편집 중인 작업공간은 브라우저 `localStorage`에 자동 저장됩니다.

자동 저장 대상:

- 노드와 연결
- 노드 위치
- 블록 설정값
- 사용자 블록 정의
- 선택한 Quick Draw 종류
- 작업공간 pan / zoom 상태

새로고침하면 직전 편집 상태를 자동 복구합니다.

사용자 블록 내부를 편집 중일 때는 임시 내부 그래프가 일반 작업공간 자동저장을 덮어쓰지 않도록 자동저장을 잠시 멈춥니다. 내부 편집을 저장하고 원래 작업공간으로 돌아온 뒤 새 정의와 함께 다시 저장됩니다.

### 자동 저장하지 않는 것

**학습된 가중치와 런타임 변수 값은 자동 저장하지 않습니다.**

즉 새로고침 시 그래프 구조와 편집 상태는 돌아오지만, 학습 중 변경된 `W`, `b`, gradient 누적 변수 등은 초기 상태에서 다시 시작합니다.

학습된 값을 보존하려면 `.mmlweights` 또는 `.mmlab` 저장 기능을 사용합니다.

## 평가도 수학 블록으로 구성

별도의 `Model.evaluate()`나 완성된 정확도 블록은 없습니다.

확률 벡터를 `p`, 정답 one-hot을 `y`라고 하면 다음처럼 구성할 수 있습니다.

```text
m = max(p)
mask = [p = m]
predict = mask / sum(mask)
hit = y · predict
```

전체 테스트에서는

```text
correct ← correct + hit
accuracy = correct / test_count
```

를 사용합니다.

종류별 출력 확률도 외적과 누적을 이용해 직접 만들 수 있습니다.

```text
prob_sum ← prob_sum + (y ⊗ p)
class_count ← class_count + y
prob_mean = prob_sum / (class_count ⊗ ones)
```

## 선택 계산과 손그림 테스트

### 선택 계산

작업공간 전체가 아니라 **선택한 블록과 그 조상 그래프만 실행**할 수 있습니다.

학습 그래프와 테스트 그래프를 같은 작업공간에 만들어도 테스트 출력만 선택하면 학습 반복을 다시 돌리지 않고 평가 부분만 실행할 수 있습니다.

반복의 hot path는 미리 분석한 실행 계획을 재사용합니다.

### 손그림 테스트

오른쪽 그림판에 직접 그림을 그리고 학습된 모델의 최종 점수 / 확률 출력 블록을 선택해 테스트할 수 있습니다.

손그림은 Quick Draw 입력 분포에 가깝도록 28×28로 전처리된 뒤 선택한 예측 그래프에 입력됩니다.

추론 중에는 `반복`, `값 바꾸기`, `미분`을 실행하지 않아 학습된 파라미터를 변경하지 않습니다.

## 저장 형식

### `.mmlab` — 전체 프로젝트

상단 `내보내기` / `불러오기` 기능을 사용합니다.

저장 항목:

- 그래프 노드와 연결
- 노드 위치와 파라미터
- 사용자 블록 정의
- 런타임 변수 값(학습된 가중치 포함)
- 데이터셋 선택
- 작업공간 pan / zoom

Quick Draw 이미지 원본 바이트는 포함하지 않습니다.

### `.mmlweights` — 학습 파라미터

학습된 파라미터만 따로 저장합니다.

반복 인덱스나 평가용 누적 변수보다 실제 미분·업데이트에 사용되는 파라미터를 대상으로 하며, 불러올 때 변수 이름, 배열 모양, 데이터 클래스 순서를 확인합니다.

---

## 실행 성능 최적화

이 프로젝트는 수학 그래프의 의미를 바꾸지 않고 반복 실행 오버헤드를 줄이는 방향으로 최적화되어 있습니다.

주요 최적화:

- 같은 loss에 대한 gradient 계산 공유
- 그래프 입력 연결과 topological order 캐시
- 학습 / 선택 실행의 hot path 컴파일
- 원소별 연산 전용 `Float32Array` 커널
- 행렬 연산 전용 빠른 경로
- 결과 버퍼 arena 재사용으로 대량 임시 할당 감소
- 불필요한 gradient / runtime 배열 복사 제거
- 사용자 블록 내부 forward / backward 실행 계획 컴파일
- 사용자 블록 forward 값을 backward에서 재사용

성능 최적화의 원칙은 다음과 같습니다.

> 사용자가 만든 수학식과 계산 순서는 그대로 두고, 같은 일을 실행하는 데 필요한 탐색·할당·복사를 줄인다.

벤치마크와 correctness 검사는 `bench/` 디렉터리에 있습니다.

---

## 의도적으로 제공하지 않는 것

이 프로젝트는 완성된 AI 모델을 제공하는 도구가 아니라 **AI를 이루는 수학을 직접 조립하는 도구**를 목표로 합니다.

따라서 다음과 같은 기능은 기본 블록으로 제공하지 않습니다.

- `NeuralNetwork` 클래스
- Dense / Linear 완성 레이어
- Conv2D / Pooling 완성 레이어
- Softmax 전용 AI 블록
- 완성된 모델 구조
- 한 번 누르면 모델 전체를 만들어 주는 학습 버튼
- 모델 전용 정확도 / 평가 블록
- 미니배치 전용 블록

필요한 구조는 행렬, 벡터, 일반 연산, 배열 변환, 자동미분, 상태 변경, 반복, 사용자 블록으로 직접 만듭니다.

## 실행

정적 HTML / CSS / JavaScript 프로젝트입니다.

```bash
python -m http.server 8000
```

그 뒤 브라우저에서

```text
http://localhost:8000
```

으로 접속합니다.

`index.html`을 직접 열어도 Quick Draw 데이터는 필요할 때 GitHub raw 경로에서 읽을 수 있게 구성되어 있습니다.

개발 중 오래된 JavaScript가 브라우저 캐시에 남는 것을 막기 위해 `index.html`의 정적 파일 URL에 공통 버전 쿼리를 붙여 사용합니다.
