# Machine Learning Math Project

수학 동아리 개인 심화 탐구 발표를 위한 **블록형 수학 실험 도구**입니다.

핵심 원칙은 하나입니다.

> 발표 시작 시점에는 완성된 신경망이 없다. 일반 수학 블록과 데이터 블록을 직접 연결하면서 신경망의 계산과 학습 구조를 만든다.

## 현재 구현

### 작업공간

- 터치/마우스로 블록 이동
- 출력 포트 → 입력 포트 연결
- 빈 작업공간을 드래그해 화면 이동(pan)
- `− / 100% / +` 버튼으로 작업공간 확대·축소
- `화면 초기화`로 위치와 배율을 원래 상태로 복원
- PC에서는 `Ctrl + 휠` 또는 트랙패드 핀치로 확대·축소
- 화면 밖에 놓인 블록도 작업공간을 이동해 다시 찾을 수 있음
- 선택한 블록의 수학식과 현재 값 표시
- 여러 블록을 선택해 하나의 **사용자 블록**으로 묶기
- 사용자 블록은 브라우저 `localStorage`에 저장되어 같은 기기에서 다시 사용할 수 있음

### 기본 블록

#### 입력

- 숫자
- 변수
  - 스칼라
  - 벡터
  - 행렬
  - 상수/무작위 초기값
- 그림 입력

#### 데이터

- 불러온 데이터
- 종류 고르기
- 샘플 고르기
- 데이터 샘플(반복 번호 기반)
- 그림값
- 종류 번호
- 종류 벡터(one-hot)

#### 생성·변환

- 같은 값 벡터
- 무작위 벡터
- 행렬 만들기
- 28×28 변환
- 펼치기

#### 연산

- 더하기 / 빼기 / 곱하기 / 나누기
- 제곱 / 절댓값 / 최댓값
- 합 / 평균 / 내적
- 지수 / 로그
- 행렬 × 벡터

#### 미분

- 변수 이름을 지정해 연결된 스칼라 식을 자동 미분
- 역방향 자동미분(reverse-mode automatic differentiation) 방식
- 숫자 변수와 벡터 변수 지원
- 행렬 × 벡터 연산의 기울기 전파 지원
- 사용자 블록 내부 연산도 따라가며 미분

#### 상태와 반복

- 값 바꾸기
- 둘 다 계산
- 반복
- 반복 번호를 변수에 넣어 데이터 샘플을 순서대로 사용 가능
- 한 반복 안의 변수 변경은 회차가 끝날 때 반영되어 여러 파라미터를 함께 갱신 가능

이 블록들을 조합하면 가중치 행렬, 편향, 손실 함수, 기울기 계산, 파라미터 갱신, 데이터 반복 등 **신경망 학습에 필요한 수학 과정을 직접 구성**할 수 있습니다.

## 사용자 블록

여러 연산 블록을 선택해 하나의 새 블록으로 묶을 수 있습니다.

- 내부 연결 구조와 파라미터를 저장
- 외부에서 필요한 입력은 새 블록의 입력 포트로 유지
- 출력은 하나로 모아 새 블록의 출력으로 사용
- 만든 블록을 다시 다른 계산에 사용 가능
- 사용자 블록을 포함한 식도 바깥의 미분 블록에서 미분 가능

특정 신경망 레이어를 미리 제공하는 대신, 반복해서 쓰는 수학 구조를 사용자가 직접 블록으로 정의하는 방식입니다.

## Quick Draw 데이터

`data/` 폴더에 15개 종류를 각각 10,000장씩 저장합니다.

- airplane
- apple
- bicycle
- car
- cat
- clock
- cup
- face
- fish
- flower
- guitar
- house
- star
- tree
- umbrella

각 파일은 28×28 grayscale 그림 10,000장을 연속된 `uint8` 값으로 저장한 `.bin` 파일이며 크기는 `7,840,000 bytes`입니다.

오른쪽 데이터 패널에서 사용할 종류만 선택해 메모리에 불러온 뒤, 작업공간의 데이터 블록을 통해 실제 계산 그래프에 연결할 수 있습니다.

데이터 출처: **Google Quick, Draw! Dataset**

- https://quickdraw.withgoogle.com/data
- https://github.com/googlecreativelab/quickdraw-dataset

## 프로젝트 저장과 불러오기

상단의 `내보내기` 버튼으로 현재 작업을 `.mmlab` 파일로 저장하고, `불러오기` 버튼으로 다시 복원할 수 있습니다.

저장되는 항목:

- 블록과 위치
- 블록 연결
- 블록 파라미터
- 사용자 블록 정의
- 현재 런타임 변수 값
- 선택한 Quick Draw 종류
- 작업공간 화면 위치와 확대 배율

Quick Draw 그림 데이터 자체는 저장 파일에 포함하지 않습니다. 데이터는 원래 `data/` 파일에서 다시 불러오기 때문에 신경망의 가중치가 커져도 데이터셋 때문에 저장 파일이 불필요하게 커지지 않습니다.

## 의도적으로 미리 만들지 않은 것

이 프로젝트는 완성된 AI 모델을 제공하는 도구가 아니라 **AI를 이루는 수학을 직접 조립하는 도구**를 목표로 합니다.

따라서 다음과 같은 고수준 기능은 미리 제공하지 않습니다.

- `NeuralNetwork` 클래스
- Dense/Linear 같은 완성된 신경망 레이어 블록
- 완성된 모델 구조
- 한 번 누르면 모든 학습을 수행하는 학습 버튼

대신 행렬, 벡터, 일반 연산, 자동미분, 상태 변경, 반복, 사용자 블록을 이용해 이러한 구조를 발표 과정에서 직접 만들어 갑니다.

## 실행

정적 HTML/CSS/JS 프로젝트입니다.

```bash
python -m http.server 8000
```

그 뒤 `http://localhost:8000`으로 접속합니다.

`index.html`을 직접 열어도 동작하도록 Quick Draw 데이터는 필요할 때 GitHub raw 경로를 사용할 수 있게 되어 있습니다.
