# Machine Learning Math Project

수학 동아리 개인 심화 탐구 발표를 위해 만든 **블록형 수학·머신러닝 실험 도구**입니다.

핵심 목표는 완성된 신경망을 가져다 쓰는 것이 아니라, **신경망을 이루는 수학을 직접 조립해서 실제 학습까지 수행하는 것**입니다.

> 발표 시작 시점에는 완성된 신경망이 없다.  
> 행렬, 벡터, 함수, 상태 변경, 반복을 직접 연결하면서 신경망과 역전파를 만든다.

Dense/Linear, Conv2D, Softmax, `NeuralNetwork`, `model.fit()` 같은 고수준 AI 기능은 기본 블록으로 제공하지 않습니다. 대신 일반 수학 블록과 데이터 블록을 이용해 순전파, 손실 함수, 역전파, SGD, 미니배치, 평가 계산을 직접 구성합니다.

---

## 프로젝트 특징

### 수학 블록으로 신경망 직접 구성

한 층도 완성된 레이어 블록이 아니라 다음 수식을 직접 만듭니다.

```text
h = ReLU(Wx + b)
  = max(Wx + b, 0)
```

이를 여러 번 연결하면 예를 들어

```text
784 → 64 → 32 → 15
```

같은 다층 신경망을 구성할 수 있습니다.

활성화 함수, Softmax, Cross Entropy, 정확도 계산도 모두 일반 수학 블록의 조합으로 표현합니다.

### 수동 역전파

자동미분은 사용하지 않습니다.

각 연산의 역전파 식은 사용자가 직접 정의합니다. 정의 편집기에서는 해당 블록의

- 순전파 입력값
- 순전파 출력값 `y`
- 뒤에서 들어오는 기울기 `g = ∂L/∂y`

를 사용할 수 있습니다.

예를 들어 `y = a × b`라면 사용자가 직접

```text
∂L/∂a = g × b
∂L/∂b = g × a
```

를 일반 수학 블록으로 만듭니다.

프로그램은 계산 그래프를 보고 체인 룰을 자동 적용하지 않고, 역전파 실행 순서도 자동으로 정하지 않습니다. 사용자가 뒤쪽 연산부터 직접 실행 순서를 구성합니다.

### 사용자 블록의 역전파 재사용

여러 순전파 연산을 사용자 블록으로 묶은 뒤, 그 사용자 블록 자체에도 별도의 역전파 정의를 저장할 수 있습니다.

한 번 유도하고 정의한 뒤에는 접힌 사용자 블록 하나가 `g`를 받아 각 외부 입력의 기울기를 한 번에 계산할 수 있습니다.

즉 고수준 레이어를 처음부터 제공하는 것이 아니라, **직접 이해하고 만든 수학 구조를 사용자가 스스로 추상화**합니다.

### 상태 변경과 반복

학습 과정 역시 블록으로 직접 구성합니다.

```text
gW = 직접 구성한 역전파 식
W ← W - ηgW
```

학습용 핵심 블록:

- `값 바꾸기`
- `둘 다 계산`
- `반복`

미니배치 전용 블록도 없습니다. gradient를 직접 누적하고 평균낸 뒤 갱신합니다.

```text
G ← G + gW

15개 샘플 후
W ← W - η(G / 15)
G ← 0
```

중첩 반복으로 sample, batch, epoch 구조를 만들 수 있습니다.

## 합성곱도 일반 수학 블록으로 구성

Conv2D 전용 블록은 제공하지 않습니다.

`슬라이딩 창 펼치기`는 2차원 배열에서 일정한 크기의 부분 배열을 차례로 꺼내 각 창을 한 줄로 펼칩니다. 예를 들어 28×28 입력에 3×3 창, stride 1, padding 0을 적용하면

```text
28×28
  ↓ 슬라이딩 창 펼치기 (3×3, stride 1)
676×9
```

이 됩니다.

3×3 커널을 길이 9 벡터 `k`로 두면 이미 있는 `행렬 × 벡터`로 모든 위치의 가중합을 한 번에 표현할 수 있습니다.

```text
그림값 28×28
  ↓
슬라이딩 창 펼치기
  ↓ 676×9
행렬 × 벡터 ← k ∈ R^9
  ↓ 676
배열 모양 바꾸기 (26,26)
  ↓
max(x, 0)
```

즉 완성된 합성곱 레이어를 호출하지 않고도

```text
지역 3×3 값 추출 → 커널과 내적 → 공간 모양 복원 → 활성화
```

과정을 직접 조립할 수 있습니다.

평균 풀링도 전용 Pooling 블록 없이 만들 수 있습니다. 예를 들어 26×26 배열을 2×2, stride 2로 펼치면 169×4 행렬이 되고, 여기에 `[0.25, 0.25, 0.25, 0.25]`를 곱하면 각 2×2 영역의 평균이 됩니다.

```text
26×26
  ↓ 슬라이딩 창 펼치기 (2×2, stride 2)
169×4
  ↓ 행렬 × 벡터 [1/4, 1/4, 1/4, 1/4]
169
```

수동 역전파에서는 반대로 pooled gradient를 네 위치에 `1/4`씩 나눈 뒤 `슬라이딩 창 합치기`로 26×26 위치에 되돌릴 수 있습니다.

## Softmax와 Cross Entropy 직접 만들기

Softmax 전용 블록은 제공하지 않습니다.

안정화된 Softmax는 다음처럼 구성합니다.

```text
m = max(z)
shifted = z - m
e = exp(shifted)
p = e / sum(e)
```

Cross Entropy 학습에서는 안정적인 log-softmax 형태를 사용할 수 있습니다.

```text
m = max(z)
logZ = m + log(sum(exp(z - m)))
logp = z - logZ
L = -sum(y * logp)
```

역전파 역시 결과 공식을 직접 유도해 일반 블록으로 만들 수 있습니다. one-hot 정답에서는 최종 logits의 기울기가

```text
∂L/∂z = softmax(z) - y
```

가 되므로, 이 식부터 뒤쪽 레이어 방향으로 직접 역전파를 구성할 수 있습니다.

## 사용자 블록

여러 수학 블록을 선택해 하나의 **사용자 블록**으로 묶을 수 있습니다.

예를 들어

```text
행렬×벡터 → 더하기 → max(·,0)
```

를 설명한 뒤

```text
ReLU(Wx+b)
```

라는 하나의 사용자 블록으로 추상화할 수 있습니다.

사용자 블록은 다음 기능을 지원합니다.

- 내부 노드와 연결 구조 저장
- 필요한 외부 입력을 새 블록의 입력 포트로 유지
- 다른 계산에서 반복 사용
- 별도로 직접 작성한 역전파 정의 저장
- 사용자 블록 안에 다른 사용자 블록 사용
- 사용하지 않는 사용자 블록 삭제
- 현재 작업공간, 다른 사용자 블록, 역전파 정의에서 참조 중인 블록의 실수 삭제 방지

### 내부 구조 편집

작업공간의 사용자 블록을 선택하고 `내부 구조 편집`을 누르면 평소 사용하던 작업공간이 해당 블록의 내부 그래프로 전환됩니다.

내부에서도 일반 작업과 동일하게 노드 이동, pan/zoom, 연결 변경, 블록 추가/삭제, 설정 수정, 추가 묶기를 사용할 수 있습니다.

### 역전파 정의 편집

일반 연산이나 사용자 블록을 선택하면 `역전파 직접 정의`를 열 수 있습니다.

편집기에는 원래 입력값, 순전파 출력 `y`, 출력에서 들어오는 gradient `g`가 소스로 나타납니다. 각 입력에 대해 어떤 계산 결과를 gradient로 보낼지 사용자가 직접 지정합니다.

정의가 저장된 블록 인스턴스는 `순전파` / `역전파 실행`을 선택할 수 있습니다. 역전파 실행 시 어떤 gradient 변수를 읽고 각 입력 gradient를 어떤 변수에 기록할지 직접 지정합니다.

## 평가도 수학 블록으로 구성

별도의 `Model.evaluate()`나 완성된 정확도 블록은 없습니다.

확률 벡터를 `p`, 정답 one-hot을 `y`라고 하면 다음처럼 구성할 수 있습니다.

```text
m = max(p)
mask = [p = m]
predict = mask / sum(mask)
hit = y · predict
```

전체 테스트에서는

```text
correct ← correct + hit
accuracy = correct / test_count
```

를 사용합니다.

## 실행 성능 최적화

수학 그래프의 의미를 바꾸지 않고 반복 실행 오버헤드를 줄이는 방향으로 최적화합니다.

- 그래프 입력 연결과 topological order 캐시
- 반복 실행 hot path 컴파일
- 원소별 연산 전용 `Float32Array` 커널
- 행렬 연산 전용 빠른 경로
- 결과 버퍼 arena 재사용
- 사용자 블록 순전파 실행 계획 컴파일

역전파 자체를 프로그램이 자동 최적화하거나 재작성하지는 않습니다. 사용자가 작성한 수동 계산 그래프가 그대로 실행됩니다.

## 의도적으로 제공하지 않는 것

- `NeuralNetwork` 클래스
- Dense / Linear 완성 레이어
- Conv2D / Pooling 완성 레이어
- Softmax 전용 AI 블록
- 자동미분
- 완성된 모델 구조
- 한 번 누르면 모델 전체를 만들어 주는 학습 버튼
- 모델 전용 정확도 / 평가 블록
- 미니배치 전용 블록

필요한 구조는 행렬, 벡터, 일반 연산, 배열 변환, 상태 변경, 반복, 사용자 블록, 사용자가 직접 작성한 역전파 식으로 만듭니다.
