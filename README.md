# Machine Learning Math Project

수학 동아리 개인 심화 탐구 발표를 위한 **블록형 수학·머신러닝 실험 도구**입니다.

핵심 원칙은 하나입니다.

> 발표 시작 시점에는 완성된 신경망이 없다. 일반 수학 블록과 데이터 블록을 직접 연결하면서 신경망의 계산, 손실 함수, 미분, 학습 구조를 만든다.

Dense/Linear, Softmax, 완성된 Neural Network 같은 고수준 AI 블록을 제공하는 대신 **행렬, 벡터, 사칙연산, 지수·로그, 자동미분, 상태 변경, 반복**을 조립해 실제 학습 가능한 신경망을 만들 수 있습니다.

---

## 현재 구현

### 작업공간

- 터치/마우스로 블록 이동
- 출력 포트 → 입력 포트 연결
- 빈 작업공간 드래그로 화면 이동(pan)
- 터치스크린 두 손가락 핀치 확대·축소
- `− / 100% / +` 버튼 확대·축소
- `화면 초기화`로 위치·배율 복원
- PC `Ctrl + 휠` 또는 트랙패드 핀치 확대·축소
- 화면 밖에 놓인 블록도 작업공간 이동으로 다시 접근 가능
- 선택한 블록의 수학식과 현재 값 표시
- 여러 블록을 하나의 **사용자 블록**으로 묶기
- 사용자 블록은 브라우저 `localStorage`에 저장
- 긴 반복 계산 중 진행 상황 표시
  - 현재 반복 횟수 / 전체 반복 횟수
  - 진행률(%)
  - 중첩 반복의 `epoch`, `i` 등 현재 위치
- 반복 횟수는 최대 `1,000,000`까지 설정 가능

예를 들어 `10 epoch × 5,000 step`이면 계산 중 다음과 비슷하게 표시됩니다.

```text
반복 12,436 / 50,000 · 24.9% · epoch 3/10 · i 2436/5000
```

브라우저가 완전히 멈춘 것처럼 보이지 않도록 계산 중 주기적으로 UI에 제어권을 돌려 진행 상태를 갱신합니다.

## 기본 블록

### 입력

- 숫자
- 변수
  - 스칼라
  - 벡터
  - 행렬
  - 상수/무작위 초기값
- 그림 입력

### 데이터

- 불러온 데이터
- 종류 고르기
- 샘플 고르기
- 데이터 샘플(반복 번호 기반)
- 그림값
- 종류 번호
- 종류 벡터(one-hot)

### 생성·변환

- 같은 값 벡터
- 무작위 벡터
- 행렬 만들기
- 28×28 변환
- 펼치기

### 연산

- 더하기 / 빼기 / 곱하기 / 나누기
- 제곱 / 절댓값 / 최댓값
- 배열 최댓값
- 같음? (같으면 1, 다르면 0)
- 합 / 평균 / 내적
- 지수 / 로그
- 행렬 × 벡터

`최댓값`은 두 입력을 원소별로 비교하고, `배열 최댓값`은 배열 전체에서 가장 큰 값 하나를 반환합니다.

`배열 최댓값`도 자동미분을 지원합니다. 최댓값이 여러 위치에서 같으면 해당 위치들에 기울기를 균등하게 나눕니다.

## Softmax를 수학 블록으로 만들기

Softmax 전용 블록은 제공하지 않습니다. 다음 기초 연산을 연결해 안정화된 Softmax를 직접 만들 수 있습니다.

```text
z
├─ 배열 최댓값 ───────────────┐
└─────────────── 빼기(z - max) ┘
                    ↓
                  지수
                 ↙    ↘
               합      나누기
                └──────→ 확률 벡터
```

수식으로는

```text
m = max(z)
p_i = exp(z_i - m) / Σ_j exp(z_j - m)
```

입니다.

Cross Entropy도 같은 방식으로 일반 수학 블록을 연결해 만들 수 있습니다. 예를 들어 안정화된 log-softmax는

```text
m = max(z)
logsumexp = m + log(Σ exp(z - m))
logp = z - logsumexp
L = -Σ(y · logp)
```

처럼 구성할 수 있습니다.

완성한 계산은 `블록 묶기`로 하나의 사용자 블록으로 만들 수 있습니다.

---

## 자동미분과 역전파

- 변수 이름을 지정해 연결된 **스칼라 식**을 자동 미분
- reverse-mode automatic differentiation 사용
- 스칼라·벡터·행렬 변수 지원
- 행렬 × 벡터 연산의 기울기 전파 지원
- 사용자 블록 내부 연산도 따라가며 미분
- `max`, `exp`, `log`, `sum`, `mean`, `dot`, `flatten` 등 일반 수학 연산의 VJP 구현

행렬-벡터 곱

```text
y = Ax
```

에 대해 위쪽에서 내려온 기울기를 `g = ∂L/∂y`라고 하면

```text
∂L/∂A = g xᵀ
∂L/∂x = Aᵀ g
```

를 사용합니다.

### 같은 손실 함수의 미분 공유

예전에는

```text
∂L/∂W1
∂L/∂b1
∂L/∂W2
∂L/∂b2
```

가 각각 손실 그래프 전체를 다시 순전파하고 다시 역전파했습니다.

현재는 **같은 학습 step에서 같은 스칼라 loss를 미분하는 블록들이 하나의 reverse pass를 공유**합니다.

```text
loss
 ↓
순전파 1회
 ↓
역전파 1회
 ├─ dW1
 ├─ db1
 ├─ dW2
 └─ db2
```

사용자에게 보이는 `미분` 블록의 의미는 그대로이고, 내부 실행만 중복 계산을 재사용합니다.

### 그래프 실행 구조 캐시

긴 학습에서는 블록 연결 구조가 변하지 않으므로 매 SGD step마다 연결을 다시 검색할 필요가 없습니다.

현재 자동미분과 반복 런타임은 다음 정보를 공유 캐시에 저장합니다.

- 각 노드의 입력 연결
- 출력까지의 topological order
- 반복/상태 블록의 입력 연결
- 진행률 계산에 필요한 중첩 반복 구조

따라서 hot path에서는 반복적인

```js
graph.connections.find(...)
```

대신 배열 기반 O(1) 입력 조회를 사용합니다.

또한 `계산`을 시작할 때 현재 그래프 구조를 한 번 실행 계획으로 고정(pin)합니다. 학습 중에는 노드·연결 전체의 fingerprint를 매 step 다시 계산하지 않으며, 계산이 끝난 뒤 다음 실행에서 그래프가 편집되었는지 다시 확인합니다.

이 최적화들은 **수학식이나 학습 순서를 변경하지 않고 실행 중복만 줄이는 것**을 목표로 합니다.

## 상태 변경과 반복 학습

학습용 실행 블록:

- `값 바꾸기`
- `둘 다 계산`
- `반복`

반복 번호는 지정한 변수 이름으로 `0, 1, 2, ...`처럼 실행 컨텍스트에 들어갑니다.

중첩 반복에서는 각 반복의 인덱스를 별도 컨텍스트로 관리합니다. 예를 들어

```text
epoch: 0..9
i:     0..4999
```

를 동시에 사용할 수 있습니다.

한 반복 회차 안에서 여러 `값 바꾸기`가 실행되면 새 가중치는 **회차 마지막에 함께 반영**됩니다. 따라서 `W1`, `b1`, `W2`, `b2` 등의 gradient를 같은 기존 파라미터 상태에서 계산한 뒤 동시에 SGD 업데이트할 수 있습니다.

이 블록들을 조합하면 가중치 행렬, 편향, 손실 함수, gradient, 파라미터 갱신, 데이터 순회까지 신경망 학습의 전체 과정을 블록으로 직접 표현할 수 있습니다.

```text
cat, fish, house, tree, car
```

```text
i=0 → cat #0
i=1 → fish #0
i=2 → house #0
i=3 → tree #0
i=4 → car #0

```

## 학습 후 빠른 테스트

전체 `계산`은 학습 반복까지 실행하기 때문에, 학습이 끝난 모델을 테스트할 때는 `선택 계산`을 사용할 수 있습니다.

1. 학습된 가중치를 준비합니다.
2. 반복·값 변경과 분리된 **순수 예측 출력 블록**을 선택합니다.
3. 테스트 샘플 번호만 변경합니다.
4. `선택 계산`을 누릅니다.

선택한 출력의 조상 그래프에 `반복`, `값 바꾸기`, `미분` 같은 상태 변경 연산이 있으면 실행을 거부합니다. 따라서 테스트 때문에 학습 50,000회를 다시 실행하는 일을 막을 수 있습니다.

## 직접 그린 그림 테스트

오른쪽 `그림 입력` 패널에서 직접 그린 그림을 현재 학습된 모델로 분류할 수 있습니다.

1. Quick Draw 데이터를 불러오고 모델을 학습하거나 가중치를 불러옵니다.
2. 작업공간에서 모델의 **최종 확률/점수 벡터 출력 블록**을 선택합니다.
3. 그림판에 그림을 그립니다.
4. `선택한 출력으로 손그림 테스트`를 누릅니다.
5. 선택한 예측 그래프의 `그림값` 입력만 현재 28×28 손그림으로 임시 교체합니다.
6. 가장 큰 출력 위치를 현재 로드된 Quick Draw 종류와 대응시켜 예측과 각 점수를 표시합니다.

추론 중에는 `반복`, `값 바꾸기`, `미분`을 실행하지 않으며 학습된 가중치를 변경하지 않습니다.

## 가중치 저장과 불러오기

전체 프로젝트와 별도로 **학습된 파라미터만** 저장할 수 있습니다.

상단 버튼:

- `가중치 저장`
- `가중치 불러오기`

파일 확장자는 `.mmlweights`입니다.

저장 대상은 `값 바꾸기` 블록이 실제로 갱신하는 변수들입니다. 예를 들어

```text
W1, b1, W2, b2
```

는 저장하지만 반복용 `i`, `epoch`, 테스트 인덱스 같은 값은 제외합니다.

불러올 때는 현재 그래프의 변수 이름과 배열 모양, 데이터 클래스 순서를 확인해 다른 구조의 모델에 실수로 가중치를 적용하는 것을 막습니다.

한 번 긴 학습을 끝낸 뒤 가중치 파일을 저장해두면 다음부터는 재학습 없이 Quick Draw 테스트와 손그림 테스트를 바로 수행할 수 있습니다.

## 프로젝트 저장과 불러오기

상단의 `내보내기` 버튼으로 현재 작업을 `.mmlab` 파일로 저장하고 `불러오기`로 다시 복원할 수 있습니다.

저장되는 항목:

- 블록과 위치
- 블록 연결
- 블록 파라미터
- 사용자 블록 정의
- 현재 런타임 변수 값(학습된 가중치 포함)
- 선택한 Quick Draw 종류
- 작업공간 화면 위치와 확대 배율

Quick Draw 그림 데이터 자체는 저장 파일에 포함하지 않습니다. 데이터는 원래 `data/` 파일에서 다시 불러옵니다.

`.mmlab`은 **전체 실험 상태 저장**, `.mmlweights`는 **학습된 파라미터만 저장**하는 용도로 구분할 수 있습니다.

## 사용자 블록

여러 연산 블록을 선택해 하나의 새 블록으로 묶을 수 있습니다.

- 내부 연결 구조와 파라미터 저장
- 외부에서 필요한 입력은 새 블록의 입력 포트로 유지
- 출력은 하나로 모아 새 블록의 출력으로 사용
- 만든 블록을 다른 계산에 재사용
- 사용자 블록을 포함한 식도 바깥의 미분 블록에서 미분 가능

특정 신경망 레이어를 미리 제공하는 대신 반복해서 쓰는 **수학 구조 자체를 사용자가 정의**하는 방식입니다.

## 의도적으로 미리 만들지 않은 것

이 프로젝트는 완성된 AI 모델을 제공하는 도구가 아니라 **AI를 이루는 수학을 직접 조립하는 도구**를 목표로 합니다.

따라서 다음과 같은 고수준 기능은 기본 블록으로 제공하지 않습니다.

- `NeuralNetwork` 클래스
- Dense/Linear 같은 완성된 신경망 레이어 블록
- Softmax 같은 완성된 AI 연산 블록
- 완성된 모델 구조
- 한 번 누르면 알아서 모델 전체를 만드는 학습 버튼

대신 행렬, 벡터, 일반 연산, 자동미분, 상태 변경, 반복, 사용자 블록을 이용해 구조를 직접 만듭니다.

## 실행

정적 HTML/CSS/JS 프로젝트입니다.

```bash
python -m http.server 8000
```

그 뒤 `http://localhost:8000`으로 접속합니다.

`index.html`을 직접 열어도 동작하도록 Quick Draw 데이터는 필요할 때 GitHub raw 경로를 사용할 수 있게 되어 있습니다.
